# ReverseMarket

ReverseMarket is an AI-powered reverse marketplace where customers post their requirements and dealers compete by submitting offers.

## Features

- Customer requirement posting
- Dealer product catalog
- Dealer offer submission
- AI-powered offer ranking
- Top 3 recommendations
- Order and checkout flow
- JWT authentication
- SQLite for local development
- PostgreSQL support for cloud deployment
- FastAPI backend
- HTML/CSS/JavaScript frontend

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite / PostgreSQL
- Scikit-learn
- JavaScript
- HTML
- CSS
